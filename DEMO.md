# 10-second promo recording

Shot: take a screenshot → the notch pops → drag the thumbnail into Telegram.

## Before recording

- [ ] Built-in notched display, default resolution, clean wallpaper, Dock hidden.
- [ ] Do Not Disturb on. Menu bar tidy (hide extra icons).
- [ ] Dropshot set up with both onboarding options turned on.
- [ ] Settings → Screenshots: preview 4 s, sound off.
- [ ] Telegram open on the right half of the screen, a chat selected ("Saved Messages"),
      message field empty.
- [ ] Something good-looking on the left half to capture.
- [ ] Rehearse twice: the drag should start within a second of the preview appearing.

## Recording

Record with QuickTime Player → New Screen Recording from a second Mac or an iPhone camera
if you can; ⌘⇧5 recording on the same Mac works too, but stop it from the menu bar so
Dropshot's own preview of the recording is not in the shot.

| Time | Action |
|---|---|
| 0–2 s | Pointer rests. Press ⌘⇧4, drag a region on the left. |
| 2–3 s | Release. The island springs out of the notch with the thumbnail and "Copied ✓". |
| 3–4 s | Pause one beat so the eye catches it. |
| 4–7 s | Drag the thumbnail from the notch into the Telegram chat. |
| 7–9 s | Drop. The image appears in the message field; press Return. |
| 9–10 s | Hold on the sent message. |

## After

- [ ] Trim to 10 s, export 60 fps.
- [ ] Check the island's first frame is not cut off.
- [ ] Optional second take ending with ⌘V into another app to show the clipboard.
